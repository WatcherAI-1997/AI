---

## 🎯 В ЧЕМ УНИКАЛЬНОСТЬ?

### 1. ⚡ RAG (Retrieval-Augmented Generation)
Модель Тамерлан использует систему RAG для обогащения ответов:
- 📚 **50+ источников** знаний о тюркском мире
- 🔍 **Семантический поиск** релевантной информации
- 🎯 **Контекстное обогащение** каждого ответа
- 💡 **Умнее** чем базовые модели для тюркских тем

### 2. 🗄️ Тюркская База Знаний
Встроенная база знаний включает:
- **История**: От Тюркского каганата до современности
- **Языки**: Грамматика, словари, фразы всех тюркских языков
- **Культура**: Традиции, праздники, обычаи
- **География**: Тюркский мир от Якутии до Турции
- **Личности**: Великие люди тюркской истории
- **Литература**: Классика и современность
- **Современность**: Тюркский совет, развитие

### 3. 🧠 Специализированное Поведение
- **Автоопределение языка** пользователя
- **Мультиязычные ответы** на тюркских языках
- **Тюркская идентичность** в каждом ответе
- **Контекстная память** о тюркской истории

## 🔧 ТЕХНИЧЕСКИЕ ДЕТАЛИ

### Файлы Модели:

1. **tamerlane_model.py** (Основная модель)
   - Класс `TamerlaneModel` - главная логика
   - RAG интеграция
   - Анализ запросов
   - Генерация с обогащением

2. **turkic_knowledge_base.py** (База знаний)
   - Класс `TurkicKnowledgeBase`
   - 50+ статей о тюркском мире
   - Семантический поиск
   - 8 категорий знаний

3. **turkic_dataset.py** (Датасет для обучения)
   - Класс `TurkicDataset`
   - Примеры для fine-tuning
   - Экспорт в JSONL

### API Integration:

```python
from tamerlane_model import get_tamerlane_model

# Создание модели
tamerlane = get_tamerlane_model(base_provider='anthropic')

# Генерация ответа
result = tamerlane.generate(
    messages=[
        {"role": "user", "content": "Тәмірлан туралы айтып бер"}
    ],
    base_model_fn=your_base_model_function,
    temperature=0.7
)

print(result['response'])
print(f"Enhanced: {result['enhanced']}")  # True если использовалась база знаний
```

## 🎓 ОБУЧЕНИЕ И FINE-TUNING

### Датасет:

В `turkic_dataset.py` находится обучающий датасет с примерами:
- Вопросы-ответы на казахском
- Вопросы-ответы на турецком
- Вопросы-ответы на узбекском
- Мультиязычные диалоги

### Экспорт датасета:

```python
from turkic_dataset import get_turkic_dataset

dataset = get_turkic_dataset()
dataset.export_for_finetuning('turkic_train.jsonl', format='jsonl')
```

### Fine-tuning (будущее):

Планируется поддержка fine-tuning:
- Llama 3.1 на тюркских данных
