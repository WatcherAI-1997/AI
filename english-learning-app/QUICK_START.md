# Быстрый старт - Запуск приложения

## 📱 СПОСОБ 1: На реальном телефоне (САМЫЙ ПРОСТОЙ!)

### Шаг 1: Установите Expo Go
- **Android**: [Скачать из Google Play](https://play.google.com/store/apps/details?id=host.exp.exponent)
- **iOS**: [Скачать из App Store](https://apps.apple.com/app/expo-go/id982107779)

### Шаг 2: Запустите проект
```bash
cd english-learning-app
npm start
```

### Шаг 3: Откройте на телефоне
- **Android**: Откройте Expo Go → Нажмите "Scan QR code" → Отсканируйте QR-код в терминале
- **iOS**: Откройте камеру → Наведите на QR-код → Нажмите на уведомление

**Готово!** Приложение загрузится на ваш телефон за несколько секунд.

---

## 💻 СПОСОБ 2: В веб-браузере

```bash
cd english-learning-app
npm start
```

Когда появится меню, нажмите **`w`** для запуска в браузере.

Или сразу:
```bash
npm run web
```

Приложение откроется в браузере по адресу http://localhost:19006

## 🎓 Как пользоваться приложением

### 1. Главный экран (Home)
- Видите общий обзор приложения
- Быструю статистику
- Можете перейти к любому разделу

### 2. Словарь (Vocabulary/Words)
- Нажмите на кнопку **Beginner**, **Intermediate** или **Advanced**
- Выберите слово из списка
- Откроется карточка с:
  - Переводом
  - Транскрипцией
  - Примером использования

### 3. Упражнения (Exercises/Practice)
- Появится вопрос на английском
- Выберите правильный перевод из 4 вариантов
- Зелёный цвет = правильный ответ
- Красный цвет = неправильный ответ
- После 10 вопросов увидите результат

### 4. Прогресс (Progress/Stats)
- Смотрите свою статистику
- Отслеживайте достижения
- Проверяйте активность по дням

## 🔧 Если что-то не работает

### Проблема: "Command not found: expo"
**Решение:**
```bash
npm install -g expo-cli
```

### Проблема: Не подключается к Metro bundler
**Решение:**
1. Убедитесь, что компьютер и телефон в одной WiFi сети
2. Попробуйте запустить с tunnel:
```bash
npx expo start --tunnel
```

### Проблема: Ошибки при установке зависимостей
**Решение:**
```bash
rm -rf node_modules package-lock.json
npm install
```

### Проблема: Белый экран на телефоне
**Решение:**
1. Закройте приложение в Expo Go
2. Перезапустите Metro bundler (npm start)
3. Повторно отсканируйте QR-код

## 📝 Советы по использованию

1. **Начните с Beginner уровня** - там самые простые слова
2. **Проходите тесты несколько раз** - это помогает запомнить
3. **Читайте примеры** - они показывают слова в контексте
4. **Занимайтесь регулярно** - лучше 10 минут каждый день, чем 1 час раз в неделю
