# English Learning App 📚

Мобильное приложение для изучения английского языка с интерактивными упражнениями и отслеживанием прогресса.

## Возможности

- **Словарь слов** - изучайте новые английские слова с переводом, транскрипцией и примерами
- **Интерактивные упражнения** - проверяйте свои знания через тесты и викторины
- **Отслеживание прогресса** - следите за своими достижениями и статистикой обучения
- **Три уровня сложности** - Beginner, Intermediate, Advanced
- **Примеры использования** - каждое слово с примером в контексте

## Технологии

- React Native
- Expo
- React Navigation
- AsyncStorage для сохранения прогресса

## Установка и запуск

### Предварительные требования

- Node.js (версия 14 или выше)
- npm или yarn
- Expo CLI

### Шаги установки

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd AI/english-learning-app
```

2. Установите зависимости:
```bash
npm install
```

или

```bash
yarn install
```

3. Запустите приложение:

```bash
npm start
```

или

```bash
expo start
```

### Запуск на устройствах

#### Android
```bash
npm run android
```

#### iOS
```bash
npm run ios
```

#### Web
```bash
npm run web
```

### Использование с Expo Go

1. Установите приложение Expo Go на свой телефон:
   - [Android - Google Play](https://play.google.com/store/apps/details?id=host.exp.exponent)
   - [iOS - App Store](https://apps.apple.com/app/expo-go/id982107779)

2. Запустите проект командой `npm start`

3. Отсканируйте QR-код в терминале с помощью:
   - Android: приложение Expo Go
   - iOS: камера iPhone

## Функционал экранов

### 🏠 Главный экран (Home)
- Обзор основных функций приложения
- Быстрая статистика обучения
- Ежедневные советы по изучению английского
- Навигация по разделам

### 📚 Словарь (Vocabulary)
- Переключение между уровнями сложности
- Карточки слов с переводом и транскрипцией
- Примеры использования в контексте
- Категории слов (приветствия, вежливость, дом, еда и т.д.)

### ✏️ Упражнения (Exercises)
- Интерактивные тесты на знание слов
- 10 вопросов с выбором ответа
- Подсветка правильных и неправильных ответов
- Подсчет результатов и процентов
- Возможность повторного прохождения

### 📊 Прогресс (Progress)
- Статистика изученных слов
- График недельной активности
- Отслеживание достижений
- Прогресс-бары по уровням
- Текущая серия дней обучения

## Разработка

### Добавление новых слов

Отредактируйте файл `src/data/vocabulary.js` и добавьте новые слова в соответствующий уровень:

```javascript
{
  id: 21,
  english: 'Example',
  russian: 'Пример',
  transcription: '[ɪɡˈzɑːmpl]',
  example: 'This is an example sentence.',
  category: 'education'
}
```

### Добавление новых экранов

1. Создайте новый файл в `src/screens/`
2. Добавьте экран в навигацию в `App.js`
