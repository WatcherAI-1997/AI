🔑 ПОДКЛЮЧЕНИЕ РЕАЛЬНОГО AI (опционально)
═══════════════════════════════════════════════════════════════════

По умолчанию модель работает в демо-режиме.
Для полноценных ответов подключите Claude или Gemini:

CLAUDE (Anthropic):
   1. Регистрация: https://console.anthropic.com/
   2. Создайте API ключ
   3. Бесплатно: $5 на тест

   В Colab добавьте ячейку:
   ┌─────────────────────────────────────────────┐
   │ from anthropic import Anthropic             │
   │                                             │
   │ client = Anthropic(api_key="sk-ant-...")   │
   │                                             │
   │ def claude(messages, **kwargs):             │
   │     resp = client.messages.create(          │
   │         model="claude-3-5-sonnet-20241022", │
   │         max_tokens=2000,                    │
   │         messages=messages                   │
   │     )                                       │
   │     return resp.content[0].text             │
   └─────────────────────────────────────────────┘

GEMINI (Google):
   1. Регистрация: https://makersuite.google.com/
   2. Создайте API ключ
   3. Бесплатный лимит!

   В Colab добавьте ячейку:
   ┌─────────────────────────────────────────────┐
   │ import google.generativeai as genai        │
   │                                             │
   │ genai.configure(api_key="ваш-ключ")        │
   │ gemini = genai.GenerativeModel('gemini')    │
   │                                             │
   │ def gemini_fn(messages, **kwargs):          │
   │     prompt = messages[-1]['content']        │
   │     resp = gemini.generate_content(prompt)  │
   │     return resp.text                        │
   └─────────────────────────────────────────────┘
