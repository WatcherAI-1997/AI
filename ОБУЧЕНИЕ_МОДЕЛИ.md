## 🎯 Что это?

**Tamerlane GPT** - это настоящая трансформер архитектура (как GPT), которую вы обучаете сами на своих данных.

### ✅ Полностью собственная модель:
- ✅ **Собственная архитектура** - Decoder-only Transformer
- ✅ **Собственный токенизатор** - BPE для тюркских языков
- ✅ **Собственное обучение** - PyTorch, никаких API
- ✅ **Собственные данные** - тюркская база знаний
- ✅ **Собственные веса** - обучаем с нуля

### 🏗️ Архитектура:
- Multi-head Self-Attention
- Positional Encoding
- Feed-Forward Networks
- Layer Normalization
- Dropout Regularization
- Авторегрессивная генерация

## 📖 Как это работает

### 1. Токенизация

```python
# Создание токенизатора
tokenizer = TamerlaneTokenizer(vocab_size=10000)

# Обучение на корпусе текстов
tokenizer.train(texts)

# Кодирование текста
tokens = tokenizer.encode("Тенгри жарылқасын")
# Результат: [2, 1234, 5678, 3]

# Декодирование обратно
text = tokenizer.decode(tokens)
# Результат: "Тенгри жарылқасын"
```

### 2. Архитектура модели

```
Input Tokens
    ↓
Token Embedding
    ↓
Positional Encoding
    ↓
┌─────────────────────┐
│ Transformer Block 1 │
│  • Self-Attention   │
│  • Feed-Forward     │
└─────────────────────┘
    ↓
┌─────────────────────┐
│ Transformer Block 2 │
│  • Self-Attention   │
│  • Feed-Forward     │
└─────────────────────┘
    ↓
    ...
    ↓
Layer Normalization
    ↓
Output Projection
    ↓
Logits (вероятности следующего токена)
```

### 3. Обучение

```python
# Для каждого батча:

# 1. Прямой проход
logits = model(input_ids)

# 2. Вычисление loss
loss = CrossEntropy(logits, target_ids)

# 3. Обратное распространение
loss.backward()

# 4. Обновление весов
optimizer.step()
```

### 4. Генерация

```python
# Автоиспол
нительная генерация

tokens = [<BOS>]  # Начальный токен

for i in range(max_length):
    # Предсказание следующего токена
    logits = model(tokens)
    next_token = sample(logits[-1])

    # Добавление к последовательности
    tokens.append(next_token)

    # Если встретили <EOS>, останавливаемся
    if next_token == <EOS>:
        break
```

```
      Train Loss: 7.5234
      Val Loss: 7.3456
      💾 Сохранена лучшая модель: checkpoints/best_model.pt
```

### Что означают метрики:

- **Train Loss**: Ошибка на обучающей выборке (должна уменьшаться)
- **Val Loss**: Ошибка на валидационной выборке (должна уменьшаться)
- **Если Val Loss растет** → переобучение (overfitting)
- **Целевой Val Loss**: ~3-5 для small model, ~2-3 для large model

## 💡 Советы по обучению

### 1. Начните с Small модели
Сначала обучите small модель, чтобы убедиться что все работает.

### 2. Мониторьте Val Loss
Если Val Loss начинает расти, остановите обучение (early stopping).

### 3. Увеличьте данные
Больше обучающих текстов = лучше качество. Добавьте свои тексты в `model/dataset.py`.

### 4. Экспериментируйте с гиперпараметрами
- Learning rate: 1e-4, 3e-4, 1e-3
- Batch size: 4, 8, 16, 32
- Max length: 128, 256, 512

### 5. Используйте GPU
На GPU обучение в 10-50 раз быстрее!

### 6. Сохраняйте чекпоинты
Модель автоматически сохраняется каждые 5 эпох. Можно прервать и продолжить позже.

## 🔧 Решение проблем

### Проблема: Out of Memory (OOM)

**Решение:**
- Уменьшите `BATCH_SIZE` (например, с 8 до 4)
- Уменьшите `MAX_LENGTH` (например, с 512 до 256)
- Используйте меньшую модель (`small` вместо `medium`)

### Проблема: Слишком медленное обучение

**Решение:**
- Используйте GPU
- Уменьшите `NUM_EPOCHS`
- Уменьшите количество данных (для тестирования)

### Проблема: Loss не уменьшается

**Решение:**
- Уменьшите `LEARNING_RATE` (например, до 1e-4)
- Увеличьте количество данных
- Обучайте дольше (больше эпох)

### Проблема: Модель генерирует бессмыслицу

**Решение:**
- Обучайте дольше
- Используйте большую модель
- Добавьте больше обучающих данных
- Уменьшите `temperature` при генерации
